## 2026-09-08 20:05 — Выбор стека

**Решили.**

| Слой | Выбор |
| --- | --- |
| Backend | Python 3.12, FastAPI, SQLAlchemy 2 (async), Alembic |
| База | PostgreSQL 16 |
| Frontend | React + Vite, карта — react-leaflet поверх OpenStreetMap |
| Запуск | docker-compose: `postgres`, `backend`, `frontend` |
| Качество | pytest + ruff на бэке, ESLint + сборка на фронте, CI в GitHub Actions |

**Почему.**

- Продукт клиент-серверный с отдельным фронтом и бэком, общающимися по сети, и реляционной базой — это
  требование задания, стек подобран под него.
- **FastAPI** даёт async из коробки, типизацию через Pydantic и автоматическую OpenAPI-документацию; для
  сервиса с картой и частыми короткими запросами (позиции самокатов, старт/стоп аренды) это удобно.
- **SQLAlchemy 2 async + asyncpg** — единственный зрелый async-ORM для Postgres, стиль 2.0 с типизированными
  моделями хорошо ложится на Pydantic-схемы. **Alembic** — штатные миграции для SQLAlchemy.
- **PostgreSQL 16** — реляционная база по условию; при необходимости гео-запросов можно подключить PostGIS,
  на старте достаточно колонок lat/lon.
- **React + Vite** — быстрая сборка и dev-сервер, стандартный SPA-стек.
- **react-leaflet + OpenStreetMap** — бесплатные тайлы без API-ключей, ничего не нужно регистрировать,
  чтобы поднять проект «одной командой».
- **docker-compose** — единая команда `docker compose up --build` поднимает базу, бэкенд и фронтенд.

## 2026-09-08 20:05 — Процесс работы (на весь проект)

- В `main` первый коммит — только README-заглушка и `.gitignore`. Вся работа в фича-ветках
  (`feature/day1-scaffold` и т.п.), коммиты небольшие и осмысленные, перед каждым — тесты и линт.
- По завершении этапа ветка пушится и открывается PR через `gh pr create` с описанием: что сделано,
  как проверить, чеклист. PR мержит только владелец после ревью; после мержа агент возвращается на
  `main` и делает `git pull`.
- `DEVLOG.md` — решения с датой и временем; `PROMPTS.md` — промпты владельца как есть.
- Любое допущение агента фиксируется в DEVLOG.

## 2026-09-08 20:15 — Дизайн каркаса (день 1) и допущения

**Границы этапа.** Только каркас: `GET /api/health`, подключение к базе из переменных окружения,
инициализированный Alembic, smoke-тест, страница с картой Бишкека, docker-compose, `.env.example`,
README, CI. Бизнес-логики нет.

**Структура репозитория.** Монорепо: `backend/` и `frontend/` как отдельные приложения со своими
Dockerfile, `docker-compose.yml` и `.env.example` в корне.

**Допущение: менеджер зависимостей Python — uv.** `pyproject.toml` + `uv.lock` дают воспроизводимую
установку в Docker и CI и умеют сами поставить нужный Python 3.12. Проект объявлен как «виртуальный»
(без build-system): пакет `app/` импортируется из корня `backend/`, как принято для FastAPI-приложений.

**Допущение: структура бэкенда.** К запрошенным `app/api`, `app/models`, `app/schemas`, `app/services`
добавлены `app/core` (настройки) и `app/db` (engine, session, `Base`). Так модели и сервисы не тянут
конфигурацию друг из друга.

**Допущение: конфигурация базы.** Настройки читаются через pydantic-settings из переменных
`POSTGRES_HOST/PORT/USER/PASSWORD/DB`; из них собирается `DATABASE_URL` для asyncpg. Те же переменные
питают контейнер Postgres в compose — единый источник правды в `.env`.

**Допущение: `/api/health` — liveness без обращения к базе.** Тест на health не требует поднятого
Postgres, поэтому CI пока работает без сервиса базы. Readiness-проверка с `SELECT 1` появится вместе
с первой реальной работой с БД.

**Допущение: применение миграций.** В compose бэкенд стартует командой
`alembic upgrade head && uvicorn ...` — это проверяет подключение к базе из env при каждом старте.

**Допущение: фронтенд в Docker отдаётся nginx.** Многостадийная сборка (`npm run build` → nginx),
`/api/` проксируется на `backend:8000`. Клиент и API живут на одном origin, CORS не нужен.
Для локальной разработки без Docker Vite dev-сервер проксирует `/api` на `localhost:8000`.

**Допущение: порты на хосте.** Фронтенд `3000`, бэкенд `8000`, Postgres `5432`; все настраиваются
через `.env` (`FRONTEND_PORT`, `BACKEND_PORT`, `POSTGRES_PORT`).

**Допущение: TypeScript на фронте.** Шаблон Vite `react-ts`; типизация дешевле на старте, чем потом.

**Допущение: центр карты.** Бишкек, `[42.8746, 74.5698]`, zoom 13.

**Допущение: языки.** Документация (README, DEVLOG, PROMPTS, описания PR) — на русском, код,
комментарии и сообщения коммитов — на английском.

**Допущение: переносы строк.** `.gitattributes` с `* text=auto eol=lf`, чтобы файлы из Windows-окружения
не попадали в Linux-контейнеры с CRLF.

**Тесты.** pytest + pytest-asyncio (`asyncio_mode = auto`) и httpx `AsyncClient` поверх ASGI —
тот же клиент пригодится для async-тестов с базой. ruff — линт и форматирование.

**CI.** GitHub Actions на `push` в `main` и на `pull_request`: job `backend` (ruff check, ruff format
--check, pytest) и job `frontend` (`npm ci`, ESLint, `npm run build`).
